## News Pipeline 修复与测试

### `openclaw agent` 命令语法踩坑
- ❌ `-m @/path/to/file` 不支持！`@` 前缀会被当作纯文本传给 agent，不会读取文件内容
- ✅ 正确做法：Node.js 中用 `fs.readFileSync()` 读取文件内容，通过 `-m` 直接传入
- 必须指定 `--session-id`（或 `--agent`/`--to`）作为会话目标
- `[plugins]` 日志走 stdout，会混入 `--json` 输出，解析前需过滤
- JSON 输出结构：`{ runId, status, summary, result: { payloads: [{ text }] } }`
- 默认超时 600s

### 子模型 JSON 转义问题
- 子模型生成的 JSON 中，summary 字段里的中文引号（如 `"Token焦虑"`）会破坏 JSON 结构
- 两层防护：
  1. 任务提示加 JSON 转义规则（提醒 LLM 正确转义引号）
  2. 新增 `repairJSON()` 函数自动修复未转义引号
- repairJSON 策略：字符级扫描，字符串值中遇到 `"` 后若下一个非空白字符不是 `},],:,` 则转义为 `\"`
- 测试结果：任务提示的转义规则生效了，子模型第二次生成了合法 JSON，repairJSON 未触发但作为兜底保留
