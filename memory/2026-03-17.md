### 双模式设计
- **Playwright 模式**：完整浏览器渲染，支持 JS 动态站（腾讯/网易/凤凰等）
- **HTTP 回退模式**：Node.js fetch + 正则提取，仅静态站可用
- WSL 环境缺系统依赖（libnspr4/libnss3/libnssutil3/libasound），Playwright 无法启动
- 自动降级到 HTTP 模式

### Pipeline 流程（orchestrator.js）

**4 阶段流水线：**
1. **并行爬取**：child_process.spawn 分批启动子进程，每个子进程独立爬一个站
   - 子进程使用 `--force-http` 模式（避免多进程抢浏览器）
   - 每个子进程超时 120 秒（内容提取时 600 秒）
   - 结果写入 `temp/<nameEn>.json`
2. **汇总数据**：读取所有 temp JSON，合并去重，统计成功/失败数
3. **创建飞书文档**：通过 Feishu API 创建文档，写入分类新闻
   - 授权权限（full_access → 降级 manage_collaborator）
   - 文档结构：标题 → 站点(H1) → 栏目(H2) → 新闻(Bullet)
4. **推送消息**：飞书 IM 发送文档链接给用户

**CLI 参数：**
- `--site`：指定单站
- `--limit`：每栏目条目数（默认 20）
- `--parallel`：并行数（默认 4）
- `--skip-feishu`：跳过飞书（测试模式）
- `--content`：抓取新闻正文（新增，尚未测试）
